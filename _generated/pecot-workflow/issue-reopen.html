issue reopen

issue reopen

閉じた Issue を開き直し、ボードの status も設定します。

閉じた Issue を開き直し、プロジェクトのボードの status を設定します。

--status の値を設定します。渡さなければ ready にします。

status を設定してから 3 秒待ち、Issue をもう一度開き直します。ボードの自動化が Issue を閉じ直すことがあるためです。

--comment を付けると、Issue を開き直した後で、渡した理由をコメントとして投稿します。

--comment を付けて実行するたびに、コメントが 1 件増えます。

ボードに無い Issue は、warning を出して開き直し、status は変えません。

ボードの項目がアーカイブ済みのときは、status を設定する前にアーカイブを解き、updated: Issue <ref> unarchived on the board の行を出します。

組み込みの Status が Done の項目は、Issue を開き直す前に値を消し、removed: Issue <ref> Status Done on the board の行を出します。

Done が残ると、ボードの自動化（Auto-close issue）が Issue を閉じ直すことがあります。

参照の短い形の N は、pecot --repo の値で補います。その値が無ければ、今のディレクトリの git remote で補います。

--dry-run を付けると、Issue とボードの項目を読みます。開き直し・アーカイブの解除・Done の消去・status の設定・コメントの投稿を dry-run の行に出し、何も書きません。

--project で、使うプロジェクトの設定の名前を渡します。省くと、Issue のリポジトリを含む設定を使い、2 つ以上あるときは、そのうちアクティブな設定を使います。

対象のリポを repositories か aggregation_repo に持つプロジェクトの設定が要ります。2 つ以上あるときは、アクティブなプロジェクトか --project で選びます。

ホストの GitHub トークンが要ります。

使用例

Issue を active で開き直し、理由を残します。

pecot issue reopen example-org/my-repo/12 --status active --comment "The fix did not hold."

Issue を開き直さずに、する予定を出します。

pecot issue reopen example-org/my-repo/12 --dry-run

引数

<issue_ref>

Issue の参照です。owner/repo/N か、番号だけの短い形 N で渡します。 短い形の N は、pecot --repo の値で補います。その値が無ければ、今のディレクトリの git remote で補います。

指定:

必須

型:

string

MCP での名前:

issue_ref

--comment, -c

開き直す理由です。コメントとして投稿します。

指定:

省略可

型:

string

MCP での名前:

comment

--dry-run, -n

何も書かずに、する予定だけを出すかどうかです。

指定:

省略可

型:

boolean

MCP での名前:

dry_run

既定値:

false

--project

.pecot/config/projects の下にある、プロジェクトの設定の名前です。.json を付けずに渡します。省くと、Issue のリポジトリを含む設定を使います。

指定:

省略可

型:

string

MCP での名前:

project

--status, -s

開き直した後の status です。backlog・pending・blocked・ready・active・in_review・archived のどれかを渡します。

指定:

省略可

型:

string

MCP での名前:

status

既定値:

"ready"

出力

標準出力には何も出しません。

MCP の結果の項目

項目名

型

説明

issue

string

再び開いた Issue です。owner/repo/N の形です。

status

string

ボードに設定した Status です。Issue がボードに無いときと、Status が設定されていないときは入りません。

unarchived

boolean

ボードの項目の Archived を解いたかどうかです。

doneCleared

boolean

ボードの項目の組み込みの Status の Done を消したかどうかです。

commented

boolean

理由をコメントに投稿したかどうかです。

dryRun

true

dry_run のときだけ true で入ります。何も書いていません。

エラーと警告の項目については、共通仕様の出力を参照してください。

  • 標準エラー: 標準エラーに、結果の行を出します。updated（アーカイブの解除）、removed（Status の Done の消去）、set（status）、reopened（Issue）、created（コメント）です。Issue がボードに無いときと、status がプロジェクトに設定されていないとき、Status の Done を消せないときは、warning の行を出します。値が blocked のときは、hint の行が pecot project init の実行を案内します。失敗ごとに error の行を出します。

ID

要件

PW-ISSUE-REOPEN-01

閉じた Issue の参照を渡すと、その Issue を reopen します

PW-ISSUE-REOPEN-02

Issue を reopen すると、ボードの status を --status の値にします

PW-ISSUE-REOPEN-03

--status を省いて打つと、ボードの status を ready にします

PW-ISSUE-REOPEN-04

status を設定すると、3 秒待ってからもう一度 reopen します

PW-ISSUE-REOPEN-05

--comment を付けて打つと、reopen の後に理由をコメントに投稿します

PW-ISSUE-REOPEN-06

--comment を付けて 2 回打つと、そのたびにコメントを投稿します

PW-ISSUE-REOPEN-07

status を設定すると、set の行を標準エラーに出します

PW-ISSUE-REOPEN-08

Issue を reopen すると、reopened の行を標準エラーに出します

PW-ISSUE-REOPEN-09

コメントを投稿すると、created の行を標準エラーに出します

PW-ISSUE-REOPEN-10

もし Issue がボードに無いなら、warning の行を標準エラーに出します

PW-ISSUE-REOPEN-11

もし Issue がボードに無いなら、status を変えずに reopen だけを行います

PW-ISSUE-REOPEN-12

もし status がプロジェクトに設定されていないなら、warning の行を標準エラーに出します

PW-ISSUE-REOPEN-13

もし 2 回目の reopen の後も Issue が open でないなら、終了コード 1 で終わります

PW-ISSUE-REOPEN-14

もしコメントの投稿に失敗したなら、コメントを投稿できなかったと分かる error を出して、終了コード 1 で終わります

PW-ISSUE-REOPEN-15

もし --status が有効な値でないなら、終了コード 1 で終わります

PW-ISSUE-REOPEN-16

もし対象のリポを含む設定が 2 つ以上あり、アクティブなプロジェクトがそのどれも指さないなら、候補の名前と --project の案内を出して終了コード 1 で終わります

PW-ISSUE-REOPEN-17

もしリポジトリがプロジェクトに無いなら、終了コード 1 で終わります

PW-ISSUE-REOPEN-18

もし GitHub API がエラーを返したなら、終了コード 1 で終わります

PW-ISSUE-REOPEN-19

もし Issue の参照の形が誤っているなら、終了コード 2 で終わります

PW-ISSUE-REOPEN-20

もし status が blocked でボードが Blocked を定義していないなら、project init で足し方を案内する hint の行を標準エラーに出します

PW-ISSUE-REOPEN-21

--dry-run を付けて打つと、Issue を開き直さずボードにも書かず、する操作を dry-run の行で標準エラーに出し、終了コード 0 で終わります

PW-ISSUE-REOPEN-22

ボードの項目がアーカイブ済みの Issue を開き直すと、Status を設定する前にアーカイブを解きます。updated: Issue <ref> unarchived on the board の行を標準エラーに出します

PW-ISSUE-REOPEN-23

もしアーカイブを解けないなら、Issue を開かずに終了コード 1 で終わります。error: could not unarchive Issue <ref> on the board: ... の行を標準エラーに出します

PW-ISSUE-REOPEN-24

もし Status の書き込みに失敗したなら、書けなかった Status の warning の行を標準エラーに出し、reopen とコメントの投稿を続けます。選択肢の ID が古くて書けないときは、ID を読み直す project activate の案内を添えます

PW-ISSUE-REOPEN-25

もし --comment が空白だけなら、Issue を開き直さずボードにも書かずに、終了コード 1 で終わります

PW-ISSUE-REOPEN-26

ボードの項目の組み込みの Status が Done の Issue を開き直すと、開き直す前に Status の値を消します。removed: Issue <ref> Status Done on the board の行を標準エラーに出します

PW-ISSUE-REOPEN-27

もし Status の Done を消せないなら、ボードの自動化が閉じ直しうることを伝える warning の行を標準エラーに出し、reopen とコメントの投稿を続けます

PW-ISSUE-REOPEN-28

もし対象のリポを含む設定が無いなら、error の行を出して、終了コード 1 で終わります

PW-ISSUE-REOPEN-29

--project に設定の名前を渡して打つと、対象のリポを含む設定が 2 つ以上あっても、その設定を使います
