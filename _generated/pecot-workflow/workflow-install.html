workflow install

workflow install

pecot が同梱する GitHub Actions のワークフローの雛形を、リポに書き出します。

名前の雛形を、--directory のリポに書き出します。review の置き先は .github/workflows/pecot-review.yml です。

親のディレクトリが無ければ作ります。

書き出した後に、次にすることを標準出力に出します。Claude の GitHub App を入れること、モデルの認証を設定すること、pecot workflow doctor で確かめることです。

ファイルが既にあるときは、--force が無ければ止まります。

--force では、利用者が begin と end の印の間に足した行を、上書きの前に warning で出します。

--check では何も書きません。ファイルの 1 行目の版が同梱の雛形と同じかを確かめます。ファイルが無いか古いときは、更新のコマンドを出して失敗します。

--dry-run では、予定の行を出し、何も書きません。

合言葉や上限など利用者が変える値は、リポの変数にあります。ファイルを上書きしても消えません。

使用例

自動レビューのワークフローを書き出します。

pecot workflow install review

置いたワークフローが新しいかを確かめます。

pecot workflow install review --check

置いたワークフローを、同梱の版に更新します。

pecot workflow install review --force

引数

  • check・force は、同時に指定できません。

  • check・dry_run は、同時に指定できません。

<name>

雛形の一覧の名前です。いまは review だけです。

指定:

必須

型:

string

MCP での名前:

name

--check

書き出さずに、置いたファイルの版が同梱の雛形と同じかを確かめるかどうかです。

指定:

省略可

型:

boolean

MCP での名前:

check

既定値:

false

--directory, -D

対象の Git リポジトリの中のディレクトリです。サブディレクトリでも、リポのルートを使います。絶対パスと相対パスのどちらも渡せます。省くと、今のディレクトリです。 今のディレクトリです。

指定:

省略可

型:

string

MCP での名前:

directory

--dry-run, -n

何も書かずに、書く予定だけを出すかどうかです。

指定:

省略可

型:

boolean

MCP での名前:

dry_run

既定値:

false

--force

ファイルが既にあるときに上書きするかどうかです。

指定:

省略可

型:

boolean

MCP での名前:

force

既定値:

false

出力

書き出したときだけ、次にすることを番号付きの行で出します。

MCP の結果の項目

項目名

型

説明

path

string

リポのルートからのワークフローのファイルのパスです。

version

number

同梱の雛形の版です。

installedVersion

number

置いてあったファイルの版です。ファイルが無いか、版の目印が無いときは入りません。

written

boolean

ファイルを書いたかどうかです。check と dry_run のときは、いつも false です。

upToDate

boolean

check のときだけ入ります。置いたファイルの版が同梱の雛形と同じかどうかです。

removedLines

array

既にあるファイルを上書きするときだけ入ります。利用者が印の間に足した行で、雛形の中身に置き換わります。

dryRun

true

dry_run のときだけ true で入ります。何も書いていません。

エラーと警告の項目については、共通仕様の出力を参照してください。

  • 標準エラー: 標準エラーに、書いたファイルの結果の行（created・updated）を出します。--dry-run のときは予定の行（dry-run）を、--check で版が同じときは unchanged の行を出します。消える行があると warning の行を出します。失敗では error の行を出します。

説明

終了コード

already-exists

2

not-ready

--check で、ファイルが無いか、版が同梱の雛形より古いです。

1

invalid-input

名前が雛形の一覧に無いか、--check を --force・--dry-run と一緒に渡したか、--directory が無いパス・ファイル・読めないディレクトリです。ほかのコマンドラインの誤りも含みます。

2

git-unresolved

--directory が Git リポジトリの外です。

1

other

ほかの名前に当たらない失敗です。ファイルを書けないときも含みます。MCP のツールでは、コマンドの想定外の例外も含みます。

1

session-directory-unresolved

MCP のツールだけで起きます。サーバがセッションのディレクトリを決められず、コマンドを動かしません。
