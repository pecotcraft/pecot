evidence_create

evidence_create

スクリーンショットを貼った作業エビデンスの xlsx を作ります。

EvidenceSpec の JSON を読み、スクリーンショットを書いた順で並べた xlsx を 1 つ作ります。注釈は、スクリーンショットの上に重なります。

使用例

EvidenceSpec のファイルと同じディレクトリに evidence.xlsx を作ります。

evidence_create {"input_path": "/work/evidence/spec.json"}

引数

input_path

EvidenceSpec を書いた JSON ファイルの絶対パスです。Windows 形式のパス（C:\... と \\wsl.localhost\<distro>\...）も渡せます。Windows 形式のパスは、/mnt/<drive>/ の下か WSL の中の絶対パスに変換します。

指定:

必須

型:

string

out_path

書き出す xlsx の絶対パスです。Windows 形式のパスも、input_path と同じように渡せます。 省くと、input_path と同じディレクトリの evidence.xlsx に書きます。

指定:

省略可

型:

string

出力

MCP の結果の項目

項目名

型

説明

annotations

number

足した注釈の数です。成功のときだけ入ります。

convertedPaths

object

invalid-path のときの、拒否の前に変換した Windows 形式のパスです。引数の名前をキーに、from と to を持ちます。変換が無ければ入りません。

event

string

結果の種類です。成功なら result、失敗なら evidence.create.error です。パスの引数を拒否したときは入りません。

invalidPaths

array

invalid-path のときの、拒否したパスの引数の配列です。要素は <引数>=<値> の形です。

items

number

貼った画像の数です。成功のときだけ入ります。

outPath

string

書いた xlsx の絶対パスです。成功のときだけ入ります。

skipped

array

飛ばした画像の配列です。要素は、spec に書いたパスの path と、理由の reason を持ちます。理由は not-found・unsupported-format・unreadable のどれかです。飛ばした画像が無ければ空です。

violations

array

text-violation のときの、文の規則の違反の全件の配列です。要素は item・ruleId・message・text を持ちます。

エラーと警告の項目については、共通仕様の出力を参照してください。

エラー

エラー名

説明

終了コード

invalid-path

パスの引数が、相対パスか、変換できない Windows 形式のパスです。渡された値は、そのまま invalidPaths に並びます。

2

input-not-found

input_path のファイルがありません。

1

invalid-json

input_path のファイルを JSON として読めません。

1

invalid-spec

JSON が EvidenceSpec の形式に合っていません。

1

text-violation

題・見出し・注釈のどれかが文面の規則に反しています。xlsx は書きません。違反は、全件が violations に並びます。

1

text-lint-failed

文面の規則を確かめる処理が動きませんでした。

1

no-valid-images

EvidenceSpec の画像を 1 枚も貼れませんでした。

1

output-write-failed

xlsx を書き込めませんでした。

1

unknown

上のどのエラーにも当てはまらない理由で失敗しました。

1

EvidenceSpec の確認か文面の規則の確認で失敗したときは、ファイルを 1 つも書きません。

機能要件

次の 5 件の要件を、自動テストで確かめています。

ID

要件

PV-EVIDENCE-CREATE-01

input_path を渡して呼ぶと、EvidenceSpec の順に画像を貼った xlsx を書き、outPath にそのパスを載せた成功の応答を返します

PV-EVIDENCE-CREATE-02

貼れない画像が EvidenceSpec に含まれると、その画像を飛ばし、飛ばした画像と理由を skipped に載せます

PV-EVIDENCE-CREATE-03

もし題・見出し・注釈が文面の規則に反するなら、何も書かずに text-violation の失敗を返し、違反の全件を violations に載せます

PV-EVIDENCE-CREATE-04

もし input_path の中身を JSON として読めないなら、invalid-json の失敗を返します

PV-EVIDENCE-CREATE-05

もし input_path のファイルが無いなら、input-not-found の失敗を返します
