自前の GitHub App のトークンを作れなかったので、自動処理を始めなかった。

次を確かめる。失敗の理由は、この run の `gate` の job の記録に出ている。

- 変数 `PECOT_AGENT_APP_CLIENT_ID` が App の Client ID で、secret `PECOT_AGENT_APP_PRIVATE_KEY` がその App の秘密鍵か
- App がこのリポに入っているか
- App が、Repository の Contents: write・Issues: write・Pull requests: write・Actions: read を持つか
- App が、Organization の Projects: write を持つか

直した後に、起動ラベルを付け直す。
