変数 `PECOT_AGENT_APP_CLIENT_ID` が空なので、自動処理を始めなかった。

自動処理には、自前の GitHub App の次の 2 つが要る。Settings > Secrets and variables > Actions に置く。

- 変数 `PECOT_AGENT_APP_CLIENT_ID` — App の Client ID
- secret `PECOT_AGENT_APP_PRIVATE_KEY` — App の秘密鍵

置いた後に、pecot-workflow の MCP ツール `workflow_doctor`（`name` は `auto`）で、足りない設定が無いことを確かめる。
