review finish

review finish

自動レビューのワークフローの後始末の step から呼び、レビューを終えます。レビューが止まったときだけ、止まったことを知らせるコメントを PR に 1 つ書きます。

判定は、上から順に見て、最初に当たったもので決めます。

自動レビューの step が success で conclusion が空なら、書きません。PR のブランチで雛形を変えたので、action がレビューを飛ばした run です。合言葉で起こし直してもこの PR では動かないことを、skipped の行で知らせます。

job が success のときは、コメントを書かずに、理由を skipped の行に出します。

job が cancelled のときは、limit として書きます。時間の上限と、人が run を取り消したときを見分けません。

job が failure のときは、まず execution-file の最後の result の行を見ます。

execution-file の最後の result の行が error_max_turns なら、limit として書きます。

is_error が真で terminal_reason が api_error なら、failed として書きます。result の文か errors に authentication_error があれば、トークンを作り直す手順を添えます。

次に、自動レビューの step が failure で github_token が無ければ、setup-missing にします。Claude の GitHub App を入れる手順を添えます。

ほかの failure は failed として書きます。step が failure で conclusion が空なら、GITHUB_ACTOR の権限を読み、admin か write でなければ書きません。

止まった場所は、since より後に作られ、先頭が **F-NN** のインラインコメントがあるかで決めます。since が無ければ「分からない」と書きます。

本文の末尾に、GITHUB_RUN_ID と GITHUB_RUN_ATTEMPT を入れた、画面に出ない目印の行を付けます。同じ目印を持つ bot のコメントがあれば、書きません。

閉じている PR には書きません。プロジェクトの設定は読まず、ホストは github.com です。

本文は、action が持つテンプレート review-stopped を埋めて作ります。トークンの値と secret の値を書きません。

token に、github.com の PR を読み、コメントを書けるトークンが要ります。

使用例

ワークフローの後始末から、job が失敗したときにコメントを書きます。

- uses: pecotcraft/pecot/actions/review-finish@<ref>
  with:
    pr: '123'
    job-status: failure
    review-outcome: failure
    review-conclusion: failure
    review-has-token: 'true'
    execution-file: /home/runner/work/_temp/claude-execution-output.json
    since: '2026-11-17T10:00:00Z'

入力

job-status

job の終わり方（job.status）です。success・failure・cancelled のどれかです。

指定:

必須

型:

string

pr

PR の参照です。ワークフローが動くリポの PR の番号 N か、owner/repo/N で渡します。 番号だけの N は、ワークフローが動くリポ（GITHUB_REPOSITORY）の PR にします。

指定:

必須

型:

string

review-conclusion

claude-code-action の出力 conclusion です。Claude Code を動かさなかった run では空なので、空のまま渡します。

指定:

必須

型:

string

review-has-token

claude-code-action の出力 github_token があるかどうかです。true か false で渡し、トークンの値は受け取りません。

指定:

必須

型:

string

review-outcome

自動レビューの step の outcome です。success・failure・cancelled・skipped のどれかです。

指定:

必須

型:

string

execution-file

claude-code-action の出力 execution_file のパスです。

指定:

省略可

型:

string

since

自動レビューの step を始めた時刻です。ISO 8601 で渡します。この時刻より後のインラインコメントから、止まった場所を決めます。空なら渡さないのと同じです。

指定:

省略可

型:

string

token

PR を読み、コメントを書くトークンです。ワークフローの App のトークンを渡します。

指定:

省略可

型:

string

出力

  • 標準エラー: コメントを書いたときは、その URL を標準出力に出します。標準エラーに、書いたときは created の行を、書かなかったときは理由を添えた skipped の行を出します。権限を読めないときは warning の行を出して書きます。本文がテンプレートに合わないときは、error の行を出します。

エラー

エラー名

説明

invalid-input

since が ISO 8601 の時刻ではありません。何も読んでいません。

invalid-input

要る input が無いか、job-status・review-outcome・review-has-token の値が選べるもののどれでもないか、pr の形が誤っています。

content-invalid

埋めた本文がテンプレートに合いません。何も書いていません。

github-auth

GitHub トークンが見つからないか、GitHub がトークンを拒みました。

github-not-found

GitHub に対象が見つかりません。

github-rate-limit

GitHub API のレート制限に当たりました。

github-api

GitHub API がほかのエラーを返しました。

other

ほかの名前に当たらない失敗です。

コメントを書く前に止まったときは、PR に何も残りません。同じ実行の目印は、書いたコメントにだけ付くので、step を動かし直せば書きます。
