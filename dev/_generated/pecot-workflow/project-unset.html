Clear project config

project_unset

設定のキーの値を消します。キーは Epic を集めるリポジトリ（aggregation_repo）で、消した後で Epic を作るには、引数 repo が要ります。

アクティブなプロジェクトの設定ファイルから、Epic を集めるリポジトリを消します。

キーは aggregation_repo だけです。ほかのキーを渡すと、kind が invalid-input の失敗を返します。

未設定の値を消しても、何も変えずに、change を unchanged にして成功を返します。

dry_run を付けると、キーを消さずに、消す予定の前の値を previous に入れて返します。

消した後で issue_create に type の epic を渡すときは、引数 repo で作り先を渡します。

アクティブなプロジェクトが要ります（project_activate で決めます）。

使用例

Epic を集めるリポジトリの設定を消します。

{
  "name": "project_unset",
  "arguments": {
    "key": "aggregation_repo"
  }
}

設定ファイルを書かずに、消す予定を返します。

{
  "name": "project_unset",
  "arguments": {
    "key": "aggregation_repo",
    "dry_run": true
  }
}

引数

key

設定のキーです。今のキーは aggregation_repo（Epic を集めるリポジトリ）だけです。

指定:

必須

型:

string

指定可能な値:

aggregation_repo

dry_run

何も書かずに、する予定だけを返すかどうかです。

指定:

省略可

型:

boolean

既定値:

false

出力

MCP の結果の項目

項目名

型

説明

key

"aggregation_repo"

消したキーです。今は aggregation_repo だけです。

previous

string

実行前のキーの値です。未設定だったときは入りません。

change

"delete" | "unchanged"

設定がどうなったかです。delete（キーを消した）か unchanged（もともと未設定だった）です。

configPath

string

アクティブなプロジェクトの設定ファイルの絶対パスです。change がどれでも、dry_run のときも入ります。

dryRun

true

dry_run のときだけ true で入ります。何も書いていません。

エラーと警告の項目については、共通仕様の出力を参照してください。

エラー

エラー名

説明

no-active-project

アクティブなプロジェクトがありません。

config-invalid

アクティブな設定ファイルの内容が不正です。

invalid-input

key がありません。key が aggregation_repo でないときと、知らない引数などほかの引数の誤りも含みます。

project-root-not-found

プロジェクトのルートを決められません。

other

ほかの名前に当たらない失敗です。MCP のツールでは、コマンドの想定外の例外も含みます。

session-directory-unresolved

MCP のツールだけで起きます。サーバがセッションのディレクトリを決められず、コマンドを動かしません。

機能要件

次の 6 件の要件を、自動テストで確かめています。

ID

要件

PW-PROJECT-UNSET-01

値を設定していると、設定ファイルから消します

PW-PROJECT-UNSET-02

値を設定していると、結果の change を delete にし、消した値を previous に入れます

PW-PROJECT-UNSET-03

未設定だと、結果の change を unchanged にします

PW-PROJECT-UNSET-04

もしアクティブなプロジェクトが無いなら、kind が no-active-project の失敗を返します

PW-PROJECT-UNSET-05

もし aggregation_repo でないキーを渡したなら、kind が invalid-input の失敗を返します

PW-PROJECT-UNSET-06

dry_run を付けて呼ぶと、値を消さず、前の値を previous に入れ、dryRun を true にして成功を返します
