Clear project config

project_unset

設定のキーの値を消します。キーは Epic を集めるリポジトリ（aggregation_repo）で、消した後で Epic を作るには、引数 repo が要ります。

アクティブなプロジェクトの設定ファイルから、Epic を集めるリポジトリを消します。

キーは aggregation_repo だけです。ほかのキーを渡すと、kind が invalid-input の失敗を返します。

未設定の値を消しても、何も変えずに、change を unchanged にして成功を返します。

消した後は、issue_check が Epic の作り先を比べません。作り先は owner・repo で決めます。

アクティブなプロジェクトが要ります（project_activate で決めます）。

使用例

Epic を集めるリポジトリの設定を消します。

{
  "name": "project_unset",
  "arguments": {
    "key": "aggregation_repo"
  }
}

引数

key

設定のキーです。今のキーは aggregation_repo（Epic を集めるリポジトリ）だけです。

指定:

必須

型:

string

指定可能な値:

aggregation_repo

出力

MCP の結果の項目

項目名

型

説明

key

"aggregation_repo"

消したキーです。今は aggregation_repo だけです。

previous

string

実行前のキーの値です。未設定だったときは入りません。

change

"delete" | "unchanged"

設定がどうなったかです。delete（キーを消した）か unchanged（もともと未設定だった）です。

configPath

string

アクティブなプロジェクトの設定ファイルの絶対パスです。change がどれでも入ります。

エラーと警告の項目については、共通仕様の出力を参照してください。

エラー

エラー名

説明

no-active-project

アクティブなプロジェクトがありません。

config-invalid

アクティブな設定ファイルの内容が不正です。

invalid-input

key がありません。key が aggregation_repo でないときと、知らない引数などほかの引数の誤りも含みます。

project-root-not-found

プロジェクトのルートを決められません。

other

ほかの名前に当たらない失敗です。ツールの想定外の例外も含みます。

session-directory-unresolved

サーバがセッションのディレクトリを決められず、ツールを動かしません。
