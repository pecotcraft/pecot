# SECURITY.md を編集する前に

`SECURITY.md` は、GitHub の Security タブに「Security policy」として出る文書です。
読むのは、pecot の脆弱性を見つけて報告しようとしている外部の人です。

## 書くこと

次の 3 節だけを置きます。

| 節 | 中身 |
|:---|:---|
| 報告の方法 | 非公開の報告の窓口、本文に書いてほしいこと、公開 Issue と認証情報の値を書かないこと |
| 対象 | 報告を受け付けるものと、受け付けないもの |
| サポート対象のバージョン | 修正するバージョンと、最新リリースの確かめ方 |

## 書かないこと

- メンテナの運用手順（alert の Tracker の扱い、dismiss の判断、例外ファイルの書き方、費用など）
- エージェント向けの指示（「エージェントは〜する」「承認を待つ」など）
- CI・Actions・ボードの内部の仕組み

報告する人は、これらを読んでも何もできません。
運用の決めごとは、それを実行するコード・CLI の表示・テストが持ちます。文書に写して二重に持ちません。

`SECURITY.md` に上の内容を足すよう頼まれたときは、足さずに、この規則を理由として返します。
