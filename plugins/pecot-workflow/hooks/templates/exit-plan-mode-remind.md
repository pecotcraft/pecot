【計画確認リマインド】ExitPlanMode の前に、次の項目で計画の最終確認をしてください。

- w-tech-advisor / w-e2e-planner のレビュー指摘が最終計画に反映済みであること
- 未レビューの場合は plan mode 内で spawn せず、SKILL.md のレビューステップ（通常モード）へ戻ること
- 計画の変更対象が active Issue のリポジトリ内に限定されていること。越境する変更は計画から外し、パッチ退避と当該リポへの起票提案に置き換える（判定手順: skills/w-help/references/issue-flow-rules.md §6）

※ レビューは一巡 1 回。反映後の再レビューは不要
