読者: 自動レビューが止まった PR の作者。止まった理由と、続きを進める手順を読む。末尾の「例:」の形になる。

書き方:
- この本文は `pecot review finish` が埋めて PR に投稿する。エージェントも人も、手で書かない
- 結果は `failed`・`limit`・`setup-missing` のどれかにする。レビューを終えたとき（`reviewed`）は投稿しない
- 止まった場所は「指摘を投稿する前」「インラインコメントを投稿した後」「分からない」のどれかにする
- トークンの値と secret の値を書かない
- 末尾に、同じ実行で 2 度投稿しないための目印のコメントの行が付く

例:

## Review stopped — 自動レビューがターンか時間の上限で止まった

- 結果 — `limit`（ターンか時間の上限で止まった）
- 止まった場所 — インラインコメントを投稿した後（指摘の一覧はまだ無い）
- 次にすること — 変数 `PECOT_REVIEW_MAX_TURNS`・`PECOT_REVIEW_TIMEOUT_MINUTES` で上限を上げる。その後、PR に `@pecotbot review` とコメントして起動し直す
