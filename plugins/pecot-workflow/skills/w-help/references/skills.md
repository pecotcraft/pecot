# スキル一覧

| スキル | 役割 |
|:------|:-----|
| `w-active` | Readyからタスク選択 → ブランチ作成 → プランモード移行 |
| `w-repo-add` | プロジェクトにリポジトリを追加登録 |
| `w-backlog` | Epic作成 → Backlogに配置 |
| `w-breakdown` | EpicをspeckitフローでIssue分解 |
| `w-issueize` | 実装計画の各フェーズをIssue一括登録 |
| `w-merge` | PRマージ・ブランチ削除・ワークツリー後処理 |
| `w-onboarding` | 新規プロジェクトのセットアップ |
| `w-pr` | PR作成（タイトル・説明を自動生成） |
| `w-quick` | 小タスクを即Issue化 → ブランチ作成 → プランモード移行 |
| `w-ready` | Epicから1タスクを切り出し → Readyに配置 |
| `w-release` | 開発ブランチ → main へのリリースフロー |
| `w-revise` | PRレビュー指摘の分析・分類・修正実行 |
| `w-help` | pecot CLI・スキルの使い方ヘルプ |
| `w-worktree-add` | ワークツリー作成（単発／並行セット、symlink setup 含む） |
| `w-worktree-remove` | ワークツリー削除（単発／並行セット） |
