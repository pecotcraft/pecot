# Data Model: main に入れる前の変更を確かめる試験環境

永続するデータは持たない。ここには、手順とスクリプトが扱うものの形を書く。

## 場所

| 名前 | 中身 | 決まり |
|---|---|---|
| このリポ | `pecotcraft/pecot` とボード `pecot-project`（Projects の 1 番） | 確かめの書き込む先にしない |
| 検証用のリポ | `pecotcraft/pecot-sandbox` | 既定のブランチは `main`。公開のまま保つ（merge queue の条件） |
| 検証用のボード | `pecot sandbox`（Projects の 3 番） | 検証用のリポの `.pecot/config/projects/*.json` が指す |
| 検証用の clone | `.pecot/work/<Issue番号>/pecot-sandbox/` | 確かめのセッションの作業ディレクトリ。確かめが終わったら消してよい |
| 作業ツリー | 直した pecot-workflow があるブランチの checkout | `--plugin-dir` に絶対パスで渡す |

書き込む先は、作業ディレクトリのリポの設定で決まる。作業ディレクトリが検証用の clone なら、検証用に届く。

## そろえる設定

`sandbox-diff-items.json` が持つ。1 件が、次の項目を持つ。

| 項目 | 中身 |
|---|---|
| `id` | spec の FR の番号（`FR-001` など） |
| `name` | 項目の名前（`merge-settings`・`ruleset`・`board-fields`・`workflows`） |
| `compare` | 比べるなら `true`、比べないなら `false` |
| `reason` | 比べない訳。`compare` が `false` のとき必須 |
| `ignore` | 比べる項目の中で、読み飛ばすキーの一覧（`id`・`node_id`・日時など） |

比べる項目は FR-001〜003、比べない項目は FR-004〜008 と同じにする。

## 設定のずれ

比べるスクリプトの出力の 1 件。

| 項目 | 中身 |
|---|---|
| 項目の名前 | `ruleset main / merge_queue` のように、どの設定のどの部分かが分かる名前 |
| このリポの値 | 読んだ値。無ければ「なし」 |
| 検証用の値 | 読んだ値。無ければ「なし」 |

ずれが 0 件のときは、0 件と出す。

## 確かめで作ったもの

| 種類 | 名前の形 | 片付け |
|---|---|---|
| ブランチ | `cuj/<Issue番号>-<乱数>` | 消す |
| PR | 題に `[cuj <Issue番号>-<乱数>]` を含む | 開いていれば閉じる |
| Issue | 題に `[cuj <Issue番号>-<乱数>]` を含む。pecot が先頭に `[Task]` などの種類を付ける | 開いていれば閉じる |
| ボードのカード | 上の Issue・PR のカード | アーカイブする |
| リリース | タグが `cuj/<Issue番号>-<乱数>-tgz`（R6 の tgz を添える） | リリースとタグを消す |

- `<Issue番号>` は、確かめている変更の、このリポでの Issue の番号
- `<乱数>` は、同時に流した確かめの名前が重ならないための短い文字列
- この形の名前を持たないものは、片付けない

## 流す先

計画の CUJ が持つ項目。

| 値 | 意味 |
|---|---|
| 検証用の場所（リポとボードの名前） | 外へ書き込む CUJ。プロジェクトの指示にある検証用を書く |
| 手元 | 外へ書き込まない CUJ |
| 作業中のリポ | プロジェクトの指示に検証用が無いリポで、外へ書き込む CUJ。実投稿は、今のとおり main に委ねる |

## 検証用の権限

| 使う場所 | 権限 | 届く先 |
|---|---|---|
| 手元のセッション | 人の今の認証 | 絞らない |
| 人のいないセッション | 検証用のリポにだけ入れた GitHub App の installation token | 検証用のリポ。ボードに届く範囲は、research の R11-5 で確かめる |
