github ops

github ops

公式の GitHub の MCP に手の無い GitHub の操作を 1 つ行い、結果を実行のログの PECOT_RESULT の行に JSON で出します。

スキルが、公式の GitHub の MCP の actions_run_trigger で pecot-github-ops.yml を起動し、その job の step が呼びます。

どの操作も、渡された中身を書くか、読んだ値を返すだけです。何を書くかは呼び出し元が決めます。

link-branch は issue・branch・base を受け、base の先頭から Issue につながったブランチを作ります。base を省くと、リポの既定のブランチを使います。同じ名前のブランチが Issue につながっていれば、作らずに、その名前と base との分かれ目の commit を返します。

stack-register は pr・parent_pr を受け、子の PR を親の PR の直後へ登録します。親がスタックに無いときはスタックを作り、親が一番上なら足します。子が既に親の直後にあるときは書きません。

project-fields は project・changes を受けます。changes の各項目は、create・rename・delete・set-options のどれかです。並べた順に 1 つずつ書き、書く前に欄を読み直します。

set-options は、名前の合う既存の選択肢の ID・色・説明を引き継ぎます。ID を外すと選択肢が作り直され、カードの値が消えるためです。

project-view は project・name・column・row を受け、列と行を単一選択の欄で分けたボードのビューを作ります。同じ名前のビューがあれば、作らずに返します。

project-link は project・repo を受け、リポをボードにつなぎます。repo を省くと、ワークフローが動くリポを使います。

repo-settings は、delete_branch_on_merge・既定のブランチ・持ち主の種類を返します。

workflow-doctor は、secret と variable の名前と、checkout したリポに置いた pecot のワークフローの雛形の目印を返します。値は読みません。揃っているかの判定はしません。

release-create は tag・sha・body・name・prerelease を受け、sha の commit にタグを付けてリリースを作ります。name を省くとタグを名前にします。

pr-attach は pr・branch を受け、一時ブランチの画像を PR の本文に載せます。branch は pecot-attach/ で始まる名前に限ります。

pr-attach は、初めに pecot-attach/* のブランチのうち、commit の日時が 24 時間より古いものを消します。渡されたブランチは消しません。

次に、渡されたブランチの tree の直下を読みます。受けるのは、名前が英数字・_・.・- だけのファイルで、拡張子は png・jpg・jpeg・gif・webp・svg・mp4・mov・webm です。数は 50 個までです。合わないものが 1 つでもあれば、何も載せません。

画像を RUNNER_TEMP の下の新しいディレクトリに書き、そのディレクトリで gh pr edit <pr> --attach ./<名前> を起こします。gh には attach-token を渡します。gh は、本文の ./<名前> の参照を user-attachments の URL に書き換えます。

起こす前に、gh pr view で本文を読みます。載せる画像の ./<名前> を指すリンクがあれば、画像の記法に直した本文を --body-file で渡します。無ければ本文の flag を渡さず、gh が今の本文を保ちます。

最後に、成否にかかわらず、渡されたブランチを消します。

ボードは、ワークフローが動くリポと同じ組織のものだけを扱います。

workflow_dispatch で起動したワークフローの step で呼びます。workflow-doctor は、リポを checkout した後の step で呼びます。

操作に合った権限を持つ GitHub トークンが要ります。権限は pecot-github-ops.yml の雛形の先頭のコメントにあります。

使用例

Issue #7 につながったブランチを、既定のブランチの先頭から作ります。

- uses: pecotcraft/pecot/actions/github-ops@<ref>
  with:
    token: ${{ github.token }}
    operation: link-branch
    request-id: cuj-1
    params: '{"issue":7,"branch":"feat/demo/7"}'

ボード #3 に、pecot-status を列、pecot-lane を行にしたビューを作ります。

- uses: pecotcraft/pecot/actions/github-ops@<ref>
  with:
    token: ${{ steps.app-token.outputs.token }}
    operation: project-view
    params: '{"project":3,"name":"Lanes","column":"pecot-status","row":"pecot-lane"}'

pecot-attach/k3v9q2xa の画像を PR #12 の本文に載せ、ブランチを消します。

- uses: pecotcraft/pecot/actions/github-ops@<ref>
  with:
    token: ${{ github.token }}
    attach-token: ${{ secrets.PECOT_ATTACH_TOKEN }}
    operation: pr-attach
    request-id: k3v9q2xa
    params: '{"pr":12,"branch":"pecot-attach/k3v9q2xa"}'

入力

operation

行う操作の名前です。params の説明に並べた 9 つの操作のどれかを渡します。

指定:

必須

型:

string

attach-token

pr-attach だけが使う fine-grained PAT です。このリポの Contents と Pull requests の書き込みの権限が要ります。gh にだけ渡し、画像のアップロードと PR の本文の書き換えに使います。省くと空の文字列です。 省くと空の文字列です。pr-attach は github-auth になります。

指定:

省略可

型:

string

既定値:

""

params

操作ごとの値を入れた JSON のオブジェクトです。省くと {} です。 省くか空なら {} として読みます。

指定:

省略可

型:

string

既定値:

"{}"

request-id

呼び出し元が決める ID です。結果の行にそのまま入ります。省くと空の文字列です。 省くと空の文字列です。

指定:

省略可

型:

string

既定値:

""

token

操作に使う GitHub トークンです。link-branch・stack-register・repo-settings・pr-attach には GITHUB_TOKEN を、ほかの操作には App のトークンを渡します。pr-attach は、一時ブランチを読んで消すのにこのトークンを使います。

指定:

省略可

型:

string

出力

outputs はありません。実行のログに、PECOT_RESULT に続けて JSON を書いた行を 1 つ出します。JSON は operation・request_id・ok と、成功なら result、失敗なら error（kind・message）を持ちます。

  • 標準エラー: 失敗したときは、結果の行に加えて、標準エラーに error: の行を出します。

エラー

エラー名

説明

invalid-input

operation が一覧に無いか、params が JSON でないか、操作の値の形と合いません。単一選択でない欄に set-options を渡したときも含みます。pr-attach の branch が pecot-attach/ で始まらないときも含みます。GitHub を呼ばずに、step を失敗にします。

invalid-input

pr-attach で、ブランチの直下に画像が無いか、受けない名前・拡張子・種類のものがあるか、50 個を超えます。RUNNER_TEMP が無いときも含みます。何も載せずにブランチを消し、step を失敗にします。

already-exists

project-fields の create で、同じ名前の欄が既にあります。step は失敗になります。

order-conflict

stack-register で、親が一番上でないスタックにあるか、子が別のスタックにあります。書かずに、step を失敗にします。

github-auth

GitHub トークンが見つからないか、GitHub がトークンを拒みました。repo-settings で delete_branch_on_merge が返らないときも含みます。pr-attach で attach-token が空のときも含みます。step は失敗になります。

github-not-found

ボード・欄・Issue・ブランチが GitHub に見つかりません。step は失敗になります。

github-rate-limit

GitHub API のレート制限に当たりました。step は失敗になります。

github-api

GitHub API がほかのエラーを返しました。project-link でつなげなかったときも含みます。pr-attach で gh が 0 以外で終わったときも含み、gh の標準エラーを message に入れます。step は失敗になります。

other

ほかの名前に当たらない失敗です。step は失敗になります。

失敗した操作は、そこで止めます。project-fields で途中の変更が失敗したときは、書いた変更を巻き戻しません。pr-attach で gh が一部の画像を上げた後に失敗したときも、本文に載った分は戻しません。pr-attach は、失敗しても渡されたブランチを消します。成否にかかわらず、結果の行を 1 つ出します。

機能要件

次の 20 件の要件を、自動テストで確かめています。

ID

要件

PA-GITHUB-OPS-01

操作が成功すると、operation・request_id・ok: true・result を入れた PECOT_RESULT の行を 1 つ出します

PA-GITHUB-OPS-02

もし operation か params が誤っているなら、GitHub を呼ばず、invalid-input の結果の行を出して step を失敗にします

PA-GITHUB-OPS-03

もし GitHub が操作を断るか接続が切れたなら、ok: false と失敗の種類と GitHub の文を入れた結果の行を出し、step を失敗にします

PA-GITHUB-OPS-04

link-branch を呼ぶと、base か既定のブランチの先頭から Issue につながったブランチを作り、ブランチ名・元のブランチ・commit を返します。同じ名前のブランチが Issue につながっていれば、作らずに、その名前と base との分かれ目の commit を返します

PA-GITHUB-OPS-05

もし link-branch で GitHub がブランチの作成を断ったなら、GitHub の文を入れた ok: false の行を出します。GitHub が理由を返さないなら、同じ名前のブランチの有無と直し方か、確かめる所を文に入れます

PA-GITHUB-OPS-06

stack-register を呼ぶと、親の PR のスタックを作るか一番上に子の PR を足し、登録後の PR の並びを返します

PA-GITHUB-OPS-07

もし子の PR が既に親の直後へ並んでいるなら、書き込まず unchanged を返します。その順で登録できないなら、書き込まず order-conflict を返します

PA-GITHUB-OPS-08

project-fields を呼ぶと、changes を並べた順に書き、書いた後の欄と選択肢の ID を返します

PA-GITHUB-OPS-09

もし changes の項目が欄の有無や種類と合わないなら、その項目を書かずに ok: false を返します。set-options では、名前の合う選択肢の ID を引き継ぎます

PA-GITHUB-OPS-10

project-view を呼ぶと、列と行の欄で分けたビューを作ります。同じ名前のビューがあれば、作らずに created: false で返します

PA-GITHUB-OPS-11

project-link を呼ぶと、リポをボードにつなぎ、linked か already_linked を返します。つなげなければ ok: false を返します

PA-GITHUB-OPS-12

repo-settings を呼ぶと、delete_branch_on_merge・既定のブランチ・持ち主の種類を返します。delete_branch_on_merge が返らなければ github-auth を返します

PA-GITHUB-OPS-13

workflow-doctor を呼ぶと、secret と variable の名前と、置いたワークフローの雛形の目印を返します。読めない一覧は complete: false にします

PA-GITHUB-OPS-14

release-create を呼ぶと、渡したタグ・commit・本文でリリースを作り、id・タグ・URL を返します

PA-GITHUB-OPS-15

常に、トークンの値を、結果の行と標準エラーに書きません

PA-GITHUB-OPS-16

pr-attach を呼ぶと、ブランチの直下の画像を attach-token の gh で PR の本文に載せ、ブランチを消し、載せた名前と消したブランチを返します

PA-GITHUB-OPS-17

pr-attach を呼ぶと、渡されたブランチのほかの pecot-attach/* のうち、commit が 24 時間より古いものだけを消します

PA-GITHUB-OPS-18

もし pr-attach が、画像の形の誤り・空の attach-token・gh の失敗のどれかで止まったなら、ok: false を返し、渡されたブランチを消します

PA-GITHUB-OPS-19

もし pr-attach の branch が pecot-attach/ で始まらないなら、GitHub を呼ばず、ブランチを消さずに invalid-input を返します

PA-GITHUB-OPS-20

pr-attach を呼ぶと、PR の本文で載せる画像の ./<名前> を指すリンクを、画像の記法に直してから載せます
