Check Issue dependency

Check Issue dependency

issue_dependency_check

公式の MCP の issue_dependency_write に渡す値を、書く前に pecot の決まりに照らし、書いた後に動かす列を返します。GitHub を読み書きしません。

値を受けて、決まりに外れた所を problems に返します。GitHub を読み書きしません。

向き・待ち方・理由・自分自身や輪になる前提・すでにある前提・前提の数の上限を見ます。

書いた後に待つ側の Issue を置く列を expected_status に、Waits for merge の節を直した待つ側の本文を body に返します。

前提の PR を読んでいないときは、スタックできるかを決めず、expected_status を返しません。読む PR を warnings で案内します。

外れた所が無ければ、成功の結果の文は ok です。あれば、最初の外れた所の <引数>: <内容> です。

待つ側のリポを repositories に持つプロジェクトの設定が要ります。無いときは、失敗にせず not-in-project の項目を返します。

使用例

前提を付けてよいかを確かめ、書いた後に動かす列と、直した本文を返します。

{
  "name": "issue_dependency_check",
  "arguments": {
    "method": "add",
    "owner": "acme",
    "repo": "demo",
    "issue_number": 7,
    "related_issue_number": 5,
    "type": "blocked_by",
    "wait": "merge",
    "reason": "API の形が決まるまで待つ"
  }
}

引数

issue_number

待つ側の Issue の番号です。

指定:

必須

型:

integer

method

add か remove です。公式の issue_dependency_write の method と同じです。

指定:

必須

型:

string

指定可能な値:

add, remove

owner

待つ側の Issue のリポのオーナーです。

指定:

必須

型:

string

related_issue_number

前提の Issue の番号です。

指定:

必須

型:

integer

repo

待つ側の Issue のリポの名前です。

指定:

必須

型:

string

type

公式の issue_dependency_write の type と同じです。pecot は blocked_by だけを書きます。

指定:

必須

型:

string

指定可能な値:

blocked_by, blocking

project

使うプロジェクトの設定の名前です。.pecot/config/projects の下のファイル名から .json を除いたものです。省くと、待つ側のリポを含む設定を使います。2 つ以上あるときは、その中のアクティブなプロジェクトを使います。

指定:

省略可

型:

string

reads

決まりを確かめるのに要る、公式の MCP の読み取りの結果です。待つ側と前提の Issue・blocked-by・前提を閉じる PR・ボードの欄とカードを、結果のまま渡します。

指定:

省略可

型:

object

reason

add で wait が merge のときだけ渡します。マージを待つ理由の 1 行です。

指定:

省略可

型:

string

related_owner

前提の Issue のリポのオーナーです。省くと owner と同じです。

指定:

省略可

型:

string

related_repo

前提の Issue のリポの名前です。省くと repo と同じです。

指定:

省略可

型:

string

wait

add のときだけ渡します。stack（前提のブランチの上に作る。既定）か merge（マージを待つ）です。

指定:

省略可

型:

string

指定可能な値:

stack, merge

出力

MCP の結果の項目

項目名

型

説明

problems

array

決まりに外れた所の配列です。要素は field・code・message を必ず持ちます。受け付ける値が決まっているときは candidates に入れます。空なら、値をそのまま書けます。

expected_status

string

書いた後に待つ側の Issue を動かす列（pecot-status）の、ボードの選択肢の名前です。列が変わらないときと、決められないときは入りません。

body

string

待つ側の Issue の本文に、Waits for merge の節の前提の行を足すか消したものです。issue_check（update）に通して issue_write で書きます。本文を直す必要が無いときは入りません。

エラーと警告の項目については、共通仕様の出力を参照してください。

エラー

エラー名

説明

github-mcp-shape

reads に渡した値が、公式の GitHub MCP のツールの結果の形と違います。

invalid-input

引数の形が誤っています。

project-root-not-found

プロジェクトのルートを決められません。

other

ほかの名前に当たらない失敗です。ツールの想定外の例外も含みます。

session-directory-unresolved

サーバがセッションのディレクトリを決められず、ツールを動かしません。

機能要件

次の 10 件の要件を、自動テストで確かめています。

ID

要件

PW-ISSUE-DEPENDENCY-CHECK-01

method が add の値を受けると、GitHub を読み書きせずに、problems と書いた後に動かす列と直した本文を返します

PW-ISSUE-DEPENDENCY-CHECK-02

前提の PR を読んでいないか、PR の base を辿れない間、expected_status を返さず、読む PR を warnings で案内します

PW-ISSUE-DEPENDENCY-CHECK-03

前提の PR を reads で受けると、スタックできるなら Ready、できないなら Blocked を expected_status に返します

PW-ISSUE-DEPENDENCY-CHECK-04

もし前提がすでにあるか、自分自身か輪になるか、前提の数が上限を超えるなら、項目を返します

PW-ISSUE-DEPENDENCY-CHECK-05

もし決まりを確かめるのに要る読み取りが reads に無いか、続きのページがあるなら、読むツールを項目で案内します

PW-ISSUE-DEPENDENCY-CHECK-06

method が remove の値を受けると、problems と、書いた後に動かす列と、直した本文を返します

PW-ISSUE-DEPENDENCY-CHECK-07

もし remove で前提に無い Issue を指すか、wait・reason を渡すなら、項目を返します

PW-ISSUE-DEPENDENCY-CHECK-08

もし type が blocking か、reason が待ち方に合わないなら、項目を返します

PW-ISSUE-DEPENDENCY-CHECK-09

もし待つ側のリポがプロジェクトに無いなら、not-in-project の項目を返します

PW-ISSUE-DEPENDENCY-CHECK-10

もし reads の値が公式の MCP の結果の形でないなら、kind が github-mcp-shape の失敗を返します
