Export draw.io diagram

Export draw.io diagram

drawio_export

draw.io の図を、SVG と PDF に書き出します。

.drawio ファイルを 1 つ読み、静的な SVG と、同じ名前の PDF を書きます。

Playwright の Chromium が要ります。入っていなければ、先に runtime_setup を呼びます。print_hash を true にするときは、要りません。

図は、先に drawio_create を通しておきます。このツールは、図の文面を確かめません。

使用例

入力と同じディレクトリに、diagram.drawio.svg と diagram.drawio.pdf を書きます。

{
  "name": "drawio_export",
  "arguments": {
    "input_path": "/work/diagram.drawio"
  }
}

書き出さずに、図が古くなっていないかを確かめるためのハッシュだけを受け取ります。

{
  "name": "drawio_export",
  "arguments": {
    "input_path": "/work/diagram.drawio",
    "print_hash": true
  }
}

引数

input_path

入力の .drawio ファイルの絶対パスです。Windows 形式のパス（C:\... と \\wsl.localhost\<distro>\...）も渡せます。Windows 形式のパスは、/mnt/<drive>/ の下か WSL の中の絶対パスに変換します。

指定:

必須

型:

string

icons_dir

icon:// の参照を解決する起点のディレクトリの絶対パスです。プロジェクト独自のアイコンのカタログを使う図では、必ず渡します。省いてもエラーになりません。Windows 形式のパスも、input_path と同じように渡せます。 省くと、プラグインに同梱のアイコンのカタログを使います。

指定:

省略可

型:

string

out_path

書き出す SVG の絶対パスです。PDF の書き出し先は、拡張子を .pdf に替えたパスです。Windows 形式のパスも、input_path と同じように渡せます。 省くと、input_path に .svg を付けたパスに書きます。

指定:

省略可

型:

string

pdf

SVG と一緒に PDF も書くかどうかです。

指定:

省略可

型:

boolean

既定値:

true

print_hash

true にすると、書き出さずに、図が古くなっていないかを確かめるための合成ハッシュだけを返します。

指定:

省略可

型:

boolean

既定値:

false

出力

MCP の結果の項目

項目名

型

説明

convertedPaths

object

invalid-path のときの、拒否の前に変換した Windows 形式のパスです。引数の名前をキーに、from と to を持ちます。変換が無ければ入りません。

event

string

結果の種類です。書き出したなら drawio.export.done、print_hash なら drawio.export.hash です。失敗なら drawio.export.error か chromium.unavailable です。パスの引数を拒否したときは入りません。

expectedAt

string

実行時依存か Chromium が置かれるはずの場所です。runtime-dependencies-not-installed・chromium-not-installed・chromium-install-failed のときだけ入ります。

file

string

書いた SVG の絶対パスです。print_hash のときは、入力の絶対パスです。成功のときだけ入ります。

icons

number

解決した icon:// の参照の数です。成功のときだけ入ります。

invalidPaths

array

invalid-path のときの、拒否したパスの引数の配列です。要素は <引数>=<値> の形です。

pdf

string | null

書いた PDF の絶対パスです。pdf が false のときと、PDF を書けなかったときは null です。print_hash のときは入りません。

pdfFailed

boolean

PDF を書けなかったかどうかです。print_hash のときは入りません。

sourceSha256

string

print_hash のときの、入力と参照するアイコンの合成ハッシュです。図が古くなっていないかを確かめるのに使います。

エラーと警告の項目については、共通仕様の出力を参照してください。

エラー

エラー名

説明

invalid-path

パスの引数が、相対パスか、変換できない Windows 形式のパスです。渡された値は、そのまま invalidPaths に並びます。

invalid-output-extension

print_hash が false で、out_path の拡張子が .pdf です。

input-not-found

input_path のファイルがありません。

icon-unresolved

図の中の icon:// の参照が、icons_dir の下にありません。

export-failed

draw.io での SVG の書き出しに失敗しました。

output-write-failed

out_path のファイルを書けませんでした。

chromium-not-installed

Playwright の Chromium が入っておらず、PECOTV_AUTO_INSTALL_BROWSER が 1 ではありません。detail が runtime_setup の呼び出しを案内します。

chromium-install-failed

PECOTV_AUTO_INSTALL_BROWSER が 1 で、Chromium のダウンロードに失敗しました。

unknown

上のどのエラーにも当てはまらない理由で失敗しました。

入力の確認か SVG の書き出しで失敗したときは、ファイルを 1 つも書きません。PDF を書けなかったときは、SVG を残し、失敗ではなく、pngFailed か pdfFailed を true にした成功の結果で返します。

機能要件

次の 7 件の要件を、自動テストで確かめています。

ID

要件

PV-DRAWIO-EXPORT-01

input_path を渡して呼ぶと、SVG と同じ名前の PDF を書き、file と pdf に載せた成功の応答を返します

PV-DRAWIO-EXPORT-02

pdf を false にして呼ぶと、SVG だけを書きます

PV-DRAWIO-EXPORT-03

print_hash を true にして呼ぶと、何も書かず、Chromium を起動せずに、sourceSha256 に合成ハッシュを載せて返します

PV-DRAWIO-EXPORT-04

もし PDF を書けなかったなら、SVG は残し、pdfFailed が true の成功の応答を返します

PV-DRAWIO-EXPORT-05

もし SVG の書き出しに失敗したなら、何も書かずに export-failed の失敗を返します

PV-DRAWIO-EXPORT-06

もし out_path の拡張子が .svg でないなら、何も書かずに invalid-output-extension の失敗を返します

PV-DRAWIO-EXPORT-07

もし Chromium が入っていないなら、何も書かずに chromium-not-installed の失敗を返し、detail で runtime_setup の呼び出しを案内します
