リソース一覧

pecot-workflow の MCP サーバは、Issue・PR などの本文のテンプレートを MCP のリソースとして提供します。各リソースは、URI を指定して読み出せます。

URI

名前

説明

MIME タイプ

pecot-template://comment/plan

comment/plan

実装の前に投稿する、計画のコメントのテンプレートです。issue_comment に渡します。

text/markdown

pecot-template://comment/merge-diff

comment/merge-diff

マージした結果と計画の違いを伝えるコメントのテンプレートです。issue_comment に渡します。

text/markdown

pecot-template://comment/review-findings

comment/review-findings

PR に投稿する、レビューの指摘のコメントのテンプレートです。issue_comment に渡します。

text/markdown

pecot-template://comment/review-resolution

comment/review-resolution

レビューの指摘への対応を伝えるコメントのテンプレートです。issue_comment に渡します。

text/markdown

pecot-template://comment/precede-notify

comment/precede-notify

前提がマージされたことを、待っている Issue に伝えるコメントのテンプレートです。issue_comment に渡します。

text/markdown

pecot-template://issue/task

issue/task

タスクの Issue のテンプレートです。issue_create に渡します。

text/markdown

pecot-template://issue/bug

issue/bug

バグの Issue のテンプレートです。issue_create に渡します。

text/markdown

pecot-template://issue/epic

issue/epic

Epic の Issue のテンプレートです。issue_create に渡します。

text/markdown

pecot-template://issue/tracker

issue/tracker

Tracker の Issue のテンプレートです。issue_create に渡します。

text/markdown

pecot-template://issue/task-implement

issue/task-implement

実装計画の 1 つのフェーズを受け持つ、タスクの Issue のテンプレートです。issue_create に渡します。

text/markdown

pecot-template://pr/create

pr/create

PR のテンプレートです。base を空のままにすると、pr_create が決めます。pr_create に渡します。

text/markdown

pecot-template://pr/release

pr/release

リリースの PR のテンプレートです。pr_create に template を release にして渡します。

text/markdown
