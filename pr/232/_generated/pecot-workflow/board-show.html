Show board dashboard

Show board dashboard

board_show

プロジェクトの情報のダッシュボードを出します。

アクティブなプロジェクト、登録したリポジトリ、ボードの状態を返します。

ボードの状態は、Backlog・Pending・Blocked・Ready・Active・In Review にある open の項目が対象です。

登録したリポジトリの要素には、リリースの種類と Dependabot alert の状態を載せます。

alert を読めないリポジトリは、理由を入れるだけで、失敗にはしません。

repo を渡すと、ボードの項目を 1 つのリポジトリに絞ります。

Ready と Blocked にある open の Issue の blocked-by を読み、それぞれを startable・stackable・blocked のどれかに判定します。Active と In Review の Issue は読みません。

札が Needs Attention で着手の跡の無い Issue は、コメントも読みます。自動処理が書いた札かを決め、board_sync と同じ規則で数えるためです。

判定は返すだけです。Issue の列と Status は、判定に合っていなくても変えません。

前提を読めない Issue は、判定を unknown にします。

Issue の依存関係に対応していない GitHub Enterprise Server では、readiness の無いボードを返します。

board_sync が列か Status を動かすはずの Ready か Blocked の Issue があると、warnings に 1 つ入れます。件数を載せ、board_sync を案内します。件数の数え方は、board_sync と同じ規則です。前提の無い Blocked の Issue は、ブランチと PR を読んでいなくても数えます。そのため、列か Status が合っていないおそれがあると伝えます。

進行の欄がまだ旧い名前（pecot-workflow-<suffix>）なら、同じようにボードを読みます。旧い名前を載せて project_init を案内する警告を、warnings に 1 つ入れます。

Item の値に pecot-priority・pecot-size が残っていれば、残ったフィールドの名前を同じ警告に足します。値の入った Item が無いボードと、値が 10 個を超える Item だけのボードでは、残っていても気づけません。

アクティブなプロジェクトが要ります（project_activate で決めます）。

ホストの GitHub トークンが要ります。

使用例

ダッシュボードを返します。

{
  "name": "board_show",
  "arguments": {}
}

1 つのリポジトリに絞ったダッシュボードを返します。

{
  "name": "board_show",
  "arguments": {
    "json": true,
    "repo": "example-org/my-repo"
  }
}

引数

json

JSON で出力するかどうかです。結果の項目は、この値によらず同じです。

指定:

省略可

型:

boolean

既定値:

false

repo

対象のリポジトリです。owner/repo の形で明示して渡します。 省くと、ボードの項目を絞り込みません。

指定:

省略可

型:

string

出力

MCP の結果の項目

項目名

型

説明

project

object

アクティブなプロジェクトの概要です。name・host・owner・number・aggregation_repo を持ちます。ロードマップのリポジトリが未設定なら、aggregation_repo は null です。キーは snake_case です。

repositories

array

登録したリポジトリの配列です。登録順に並びます。キーは snake_case です。要素は full_name・owner・name・develop_branch・release_branch・dependabot_alerts を持ちます。ブランチが未設定なら null です。dependabot_alerts は、読めなかったときは理由の error だけを持ちます。読めたときは enabled・open_count・max_severity・alerts_url を持ちます。要素は、release_type（single・multi・nx）と packages（name と changelog の配列。無ければ空）も持ちます。package の無いリポジトリに CHANGELOG の設定があるときだけ、changelog_file も持ちます。

board

object

ボードの状態です。items の配列を持ち、Backlog・Pending・Blocked・Ready・Active・In Review にある開いた項目が入ります。キーは snake_case です。要素は id・workflow（列。無ければ null）・title・updatedAt・content・readiness を持ちます。content は number・state・url・labels・repository を持ちます。readiness は、Ready と Blocked の Issue だけが kind・stackOn・reason・text を持ち、ほかの項目は null です。サーバが Issue の依存を扱えないときは、readiness ごと入りません。要素は lane（pecot-lane の値。無ければ null）も持ちます。

lanes

array

pecot-lane の値ごとの Issue の数です。要素は name・count・startable を持ちます。選択肢の順に並び、値の無い組は name が null で末尾に来ます。ボードに pecot-lane が無ければ空の配列です。

mismatches

integer

Ready か Blocked の Issue のうち、列と Status のどちらかが判定と食い違う疑いのあるものの件数です。

エラーと警告の項目については、共通仕様の出力を参照してください。

エラー

エラー名

説明

no-active-project

アクティブなプロジェクトがありません。

config-invalid

アクティブな設定ファイルの内容が不正です。

other

予期しないエラーが起きました。

invalid-input

repo が owner/repo の形でないか、ほかの引数の誤りがあります。

github-auth

GitHub トークンが見つからないか、GitHub がトークンを拒みました。

github-not-found

GitHub に対象が見つかりません。

github-rate-limit

GitHub API のレート制限に当たりました。

github-api

GitHub API がほかのエラーを返しました。

project-root-not-found

プロジェクトのルートを決められません。

other

ほかの名前に当たらない失敗です。MCP のツールでは、コマンドの想定外の例外も含みます。

session-directory-unresolved

MCP のツールだけで起きます。サーバがセッションのディレクトリを決められず、コマンドを動かしません。
