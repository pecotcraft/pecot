Update worktree symlinks

Update worktree symlinks

worktree_link

既にある worktree に、シンボリックリンクを張るか張り直します。

worktree-config.json のリンクを、directory の worktree に張ります。all を付けると、すべてのサブの worktree に張ります。既にあるリンクは置き換えます。

リンクは、リポジトリのメインの worktree から読みます。

設定ファイルが無いときは、worktree_init で作ります。

all が無いときの対象は、directory を含む worktree のルートです。そのため、directory はサブディレクトリでも構いません。そのルートがメインの worktree のときは、失敗を返します。

all を付けてサブの worktree が無いときは、links を空の配列にして成功を返します。

リンク先が無いリンクは飛ばします。

git が追跡しているパスと、作れないリンクはエラーです。links の change を error にして warnings に入れ、成功を返します。

リンクのパスにある実体のファイルかディレクトリは、上書きの確認に答えた後にだけ置き換えます。MCP のツールには確認に答える手段が無いので、kind が aborted の失敗を返します。force を付けると、尋ねずに置き換えます。

all を付けて force が無いときは、実体のファイルを尋ねずに飛ばします。

リンクのパスが .pecot/ で始まるときは、リンクを張る前にプラグインのスクリプトを動かし、worktree に .pecot/.gitignore を書きます。

devcontainer が要ります。

remote の URL から owner/repo を読めないときは、引数 repo と比べません。repo があれば、warnings に入れて repo を使い、無ければ失敗を返します。

devcontainer の中で動かします。

リポジトリは、<プロジェクトのルート>/base/<リポジトリ> の配置になければなりません。worktree-config.json も要ります（worktree_init で作ります）。

使用例

1 つのサブの worktree にリンクを張ります。

{
  "name": "worktree_link",
  "arguments": {
    "directory": "../wt1/my-repo"
  }
}

すべてのサブの worktree で、リンクのパスにある実体のファイルを尋ねずに置き換えます。

{
  "name": "worktree_link",
  "arguments": {
    "directory": ".",
    "all": true,
    "force": true
  }
}

引数

directory

対象の Git リポジトリのパスです。絶対パスと相対パスのどちらも渡せます。

指定:

必須

型:

string

all

すべてのサブの worktree を対象にするかどうかです。

指定:

省略可

型:

boolean

既定値:

false

force

実体のファイルとディレクトリを、尋ねずに上書きするかどうかです。

指定:

省略可

型:

boolean

既定値:

false

出力

MCP の結果の項目

項目名

型

説明

links

array

各対象 worktree にある、設定の link ごとの結果の配列です。サブ worktree が無ければ空です。要素は path（symlink の絶対パス）・destination（向き先の絶対パス）・change を持ちます。change は create（新しい symlink）・update（既存を置き換えた）・skip（そのまま）・error（作れなかった）のどれかです。reason は、skip と error のときだけ入ります。

エラーと警告の項目については、共通仕様の出力を参照してください。

エラー

エラー名

説明

repo-mismatch

引数 repo が今の git remote と違います。

git-unresolved

git のリポジトリの外で repo を省きました。repo を省いて remote の URL から owner/repo を読めないときも含みます。

not-initialized

設定ファイルがありません。

config-invalid

設定ファイルの内容が不正です。

invalid-input

all なしで、directory がメインの worktree です。

aborted

上書きの確認を中断しました。MCP のツールでは、force なしで確認が要るときです。

other

メインの worktree かプロジェクトのルートが見つかりません。devcontainer の外で動かしたときと、worktree の一覧を読めないときも含みます。

invalid-input

directory が無いか、既にあるディレクトリでないか、ほかの引数の誤りがあります。

project-root-not-found

プロジェクトのルートを決められません。

other

ほかの名前に当たらない失敗です。MCP のツールでは、コマンドの想定外の例外も含みます。

session-directory-unresolved

MCP のツールだけで起きます。サーバがセッションのディレクトリを決められず、コマンドを動かしません。

この実行で既に張ったリンクは残ります。作れなかったリンクは元のままで、ほかのリンクの処理は続けます。飛ばしたリンクや作れなかったリンクがあっても、成功を返します。
